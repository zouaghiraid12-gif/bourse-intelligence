# Bourse Intelligence — بوابة المنح الذكية

تطبيق ويب ثابت (`HTML5` / `CSS3` / `Vanilla JS`) لمطابقة ملف الطالب الأكاديمي مع المنح الحكومية والجامعية العالمية، مع دعم كامل للغتين العربية والإنجليزية، وواجهة عصرية تعتمد على مؤشرات التوافق التفاعلية.

## أبرز المزايا
- **تغطية عالمية شاملة:** قائمة دول موسّعة ومصنّفة مع دعم التبديل الفوري بين العربية والإنجليزية.
- **منح حكومية وجامعية:** تقييم مرن لباقة متنوعة من المنح الحكومية ومنح الجامعات الدولية مع توضيح حالة المواعيد وملاحظات التقديم.
- **محرك مطابقة شفاف:** حساب نسبة التوافق ونقاط كل معيار (المعدل، التخصص، مستوى اللغة، ونوع التمويل) مع إمكانية حفظ المنح للمقارنة.
- **جاهز للنشر الثابت:** يعمل مباشرة دون خادم خلفي وقابل للاستضافة المجانية عبر **GitHub Pages**.
